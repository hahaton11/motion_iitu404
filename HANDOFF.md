### Что сделано в последней сессии

Живой проход выявил две вещи: рука устаёт, потому что ладонь приходится держать
строго на камеру, и бросок почти не работает. Разбор показал, что дело не
в MediaPipe — пять причин, все в своём коде:

1. **`src/gestures/voter.ts`** — кадр с уверенностью ниже порога голосовал за
   класс `idle`. Отсутствие показаний превращалось в показание в пользу покоя.
   Отсюда оба симптома: развёрнутая кисть и смазанный кадр роняли уверенность,
   такие кадры набирали большинство, и поза замирала в покое посреди действия.
   Теперь такой кадр занимает место в окне, но не голосует ни за кого.
2. **`src/motion/hand-state.ts`** — потеря руки при удержании отправляла
   отпускание с нулевой скоростью, дубль той же логики лежал в `pipeline.ts`.
   Рука теряется как раз на резком махе, поэтому бросок падал под руку.
   Теперь отпускание несёт скорость, с которой рука пропала.
3. **`src/motion/hand-state.ts`** — отпускание требовало 3 кадров подтверждения
   поверх окна голосования 4 из 6: около 250 мс идеального распознавания там,
   где его быть не может. Пока рука летит быстрее `THROW_SPEED`, хватает одного
   кадра (`FAST_RELEASE_FRAMES`).
4. **`src/dataset/protocol.ts`** — запись каждого класса шла «медленно води
   рукой», в датасете нет ни одного смазанного кадра. Классы `open` и `fist`
   теперь просят половину времени резкие махи и развёрнутую кисть.
5. **`src/motion/camera.ts`** — частота съёмки не запрашивалась, камера отдавала
   30 кадров. `frameRate: { ideal: 60 }` вдвое укорачивает выдержку и режет смаз
   в самом кадре — единственный рычаг, действующий на источник.

Правки 1–3 и 5 уже в `main`. **Правка 4 не действует, пока не переписан датасет** —
модель в `public/models/` собрана из старой записи.

### Цифры на отложенном круге записи

Скрипт оценки теперь гоняет **настоящий** голосователь из `src/gestures/voter.ts`,
а не его копию: раньше оценка меряла одно, а продукт делал другое.

| кадр ниже порога | точность | ложные действия на idle | recall `open` |
|---|---|---|---|
| голосует за idle (было) | 98.3 % | 0 % | 92.7 % |
| **занимает место, не голосует (стало)** | **99.2 %** | **0 %** | **98.3 %** |
| не попадает в окно вовсе | 98.2 % | 3.1 % | 98.3 % |

Правила по углам пальцев на тех же данных: 67.6 % точности, 46.8 % ложных
действий на бездействии.

1. **Переписать датасет** по новому протоколу — `record.html`, около 4 минут.
   Резкие махи и развёрнутая кисть там, где просит инструкция. Затем:
   ```
   npx tsx scripts/build-gesture-model.ts data/<файл>.json
   DROP=thumb,pinch ABSORB=thumb,pinch npx tsx scripts/eval-gestures.ts data/<файл>.json
   ```
   Без этого шага правка 4 не даёт ничего.
2. **Цикл 2 тестирования.** Протокол — в вault'е, `Цикл_тестирования.md`.
   Что мерить: сколько раз из десяти бросок улетает; держится ли захват при
   повороте кисти на тридцать градусов; на какой секунде устаёт рука;
   **не появилось ли ложных отпусканий при опущенной руке** — правка 3 сделала
   отпускание охотнее, это риск, который ловится только руками.
3. **Проверить в `motion.html`, даёт ли камера 60 кадров.** Если осталось 30 —
   попробовать 640×480 в `CAMERA_WIDTH`/`CAMERA_HEIGHT`: веб-камеры чаще умеют
   60 кадров на меньшем разрешении.
4. **Подбор порогов** в `src/motion/constants.ts` по живой проверке, список ниже.
5. **Запись видео для смоука:** 30 секунд жестов кнопкой в `motion.html`, затем
   `ffmpeg -i gestures.webm -pix_fmt yuv420p test-assets/gestures.y4m`.
6. **Финальная проверка деплоя** в инкогнито на чистом профиле Chrome и в Safari.

## Запуск

```
npm ci
npx playwright install chromium
npm run dev          # http://localhost:5173
npm test             # 370 unit-тестов
npm run build
npm run e2e          # смоук, видео-тест пропускается без test-assets/gestures.y4m
```

Страницы: `index.html` — продукт целиком. `motion.html` — отладка распознавания
с цифрами. `board.html`, `pocket.html` — демо. `record.html` — запись датасета.
`?input=camera` включает руку на демо-страницах, `?input=mouse` — мышь на главной.

### Инструменты замера

```
npx tsx scripts/measure-fps.ts            # FPS доски, 50 элементов, панорама и зум
npx tsx scripts/measure-fps.ts --all      # сравнить варианты оформления тени
DROP=thumb,pinch ABSORB=thumb,pinch npx tsx scripts/eval-gestures.ts data/gestures-v1.json
```

`measure-fps.ts` открывает видимое окно: в скрытом Chrome не компонует кадры
и цифра получается ложной. Варианты чередуются в одном прогоне, чтобы прогрев
машины не достался одному из них. Так нашлась просадка теней: `filter: blur`
на каждом элементе давал 41 FPS, радиальный градиент с размытием только под
поднятым элементом — 57.

## Версии

Версия 1 — тег `handoff-v1`, жесты по правилам углов пальцев. Версия 2 —
тег `handoff-v2`, жесты распознаёт kNN на записи живой руки. История общая.

Поза управляет захватом: кулак берёт, ладонь отпускает, бездействие ничего
не меняет и ставит курсор на паузу. Если модель не загрузилась, работают прежние
правила. Магнитный фокус: элемент в радиусе 80 px берётся без точного попадания.
Режим взмахов без курсора — экспериментальный, `?nav=focus`.

**Для другого человека модель надо переобучить**, порядок команд выше.

## Пороги, которые проверяются только руками

Всё в `src/motion/constants.ts`, если не указано иное.

- `SWAP_HANDEDNESS`: правая рука попадает в карточку «Правая рука».
- `FULL_CURL_RAD = 3.9`: кулак выше 0.85, ладонь ниже 0.2.
- `PALM_SIZE_MIN 0.07`, `PALM_SIZE_MAX 0.32`: подсказки «ближе» и «дальше»
  срабатывают на реальной дистанции.
- `ONE_EURO_MIN_CUTOFF 0.8`, `ONE_EURO_BETA 5`: прицел не дрожит и не отстаёт.
- `THROW_SPEED 2.2` в `src/shared/constants.ts`: бросок срабатывает, мягкое
  отпускание не превращается в бросок.
- `FAST_RELEASE_FRAMES 1`: нет ли ложных отпусканий на быстром переносе.
- `CAMERA_FPS 60`: реально ли камера столько отдаёт.
- `VOTE_THRESHOLD 0.75` в `src/gestures/voter.ts`: после переобучения модели
  порог стоит перепроверить скриптом оценки.

## Известные ограничения

- Модель обучена на одном человеке; для другого её стоит переобучить.
- Undo нигде не подключён: после «положить в карман» он дублировал бы элемент.
- Резкий бросок вне зоны кармана удаляет элемент, это объясняется в обучении.
- Голосовой ввод требует Chrome и сети; без него текст готовится заранее мышью.
- Хук `block-no-verify` из плагина ECC принимает флаг `-n` у любой утилиты
  в одной команде с `git commit` за `--no-verify`. Коммитить отдельной командой.
