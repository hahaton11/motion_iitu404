Промпт для любой сессии:

> Прочитай CLAUDE.md и docs/specs/<файл>. Выполни ТЗ полностью, строго в своей зоне.
> Тест перед реализацией, `npm test && npm run build` и коммит после каждого шага.
> В конце пройди чек-лист приёмки и дай отчёт: сделано, не сделано, решения, что проверить руками.

Ручные точки человека: создать публичный репозиторий и включить Pages, проверить камеру после S1,
записать 30 секунд жестов для смоук-теста, пройти сценарий после S4.
