# S1. Модуль распознавания

**Зона:** `src/motion/**`, `motion.html`, `public/models/**`, `test-assets/**`.
**Зависит от:** контракт `src/contracts/input.ts`, `src/shared/*`.
**Результат:** `export class CameraInput implements InputSource` из `src/motion/index.ts`.

## Цель

Стабильное и точное превращение руки в события контракта на чужих камерах и при плохом свете.
Точность достигается не дообучением модели, а слоем над точками: нормализация, гистерезис,
машина состояний, фильтрация, калибровка.

## Поведение

**Курсор.** Центр ладони как среднее точек 0, 5, 9, 13, 17, потому что кончики пальцев уходят при сжатии.
Через One Euro. Координаты экрана: зеркальный x, мёртвая зона 8% по краям кадра растягивается
на весь экран, чтобы до краёв экрана можно было дотянуться, не выводя руку из кадра.

**Машина состояний руки:** `open → closing → holding → opening → open`.
- Вход в holding: `closure > 0.75` держится 3 кадра подряд → `grab`.
- Выход: `closure < 0.45` держится 3 кадра → `release`, или `throw`, если скорость выше `THROW_SPEED`.
- Промежуток 0.45–0.75 ничего не переключает, это гистерезис.
- Point: вытянут только указательный в состоянии open, курсор сместился меньше 3% за 600 мс.
- Рука пропала на 300 мс → `handlost`. Если она была в holding, перед этим `release` с нулевой скоростью.

**Zoom.** Обе руки в holding. `factor = dist_now / dist_prev`, событие не чаще раза в кадр,
игнорировать изменения меньше 0.5%. Пока идёт zoom, grab и release этих рук не шлются повторно.

**Калибровка.** Два шага по 2,5 секунды: «Покажи открытую ладонь», «Сожми кулак».
Пороги holding и open пересчитываются между измеренными значениями.
Без калибровки работают значения по умолчанию.

## Подсказки режима «ошибка»

Одна подсказка одного кода не чаще раза в 3 секунды. Отправляются через событие `hint`.

| Код | Условие | Текст |
|---|---|---|
| `HALF_GRAB` | closure 0.45–0.75 дольше 500 мс после open | Сожми кулак полностью, чтобы взять |
| `HALF_RELEASE` | closure 0.45–0.75 дольше 500 мс после holding | Раскрой ладонь шире, чтобы отпустить |
| `HAND_NEAR_EDGE` | центр ладони ближе 5% к краю кадра | Рука у края кадра, веди её ближе к центру |
| `TOO_FAR` | размер ладони меньше порога | Подойди на шаг ближе к камере |
| `TOO_CLOSE` | размер ладони больше порога | Отойди на шаг назад, рука не помещается в кадр |
| `MOVING_TOO_FAST` | рука потеряна при скорости выше порога | Двигай рукой чуть медленнее, камера не успевает |
| `POOR_TRACKING` | уверенность handedness ниже 0.6 дольше секунды | Мало света, повернись к источнику света |
| `NO_HAND` | нет рук 3 секунды | Подними руку перед камерой, ладонью к экрану |

## Демо `motion.html`

Видео с наложенным скелетом, прицел, полоска closure для каждой руки с отметками порогов,
текущее состояние машины, лог событий, FPS и задержка обработки кадра, кнопка калибровки,
кнопка «Записать 30 секунд» — сохраняет webm для тестов.

## Тестовые данные

- `test-assets/fixtures/*.json`: записанные последовательности landmarks для жестов open, fist, pinch,
  point, half-closed. Экспорт из демо кнопкой «Сохранить кадры». Пока записей нет, сгенерировать
  синтетические позы руки в тестах.
- Тесты машины состояний на этих последовательностях: ожидаемый поток событий.
