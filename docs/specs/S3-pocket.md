# S3. Карман, режим подготовки, голос

**Зона:** `src/pocket/**`, `src/voice/**`.
**Зависит от:** S2, публичный API `Board` из `src/board/index.ts`, контракт ввода.
**Результат:** `createPocket(root, input, board): Pocket` и `createVoice(board): Voice`.

## Цель

Карман — физический буфер обмена. Элементы кладут в него и достают руками. Контент, который неудобно
создавать жестами, заранее кладётся туда мышью и клавиатурой.

## Карман

**Вид.** Полоса у нижнего края высотой около 12% экрана, в покое полупрозрачная и узкая.

**Положить.** Элемент удерживается и курсор входит в зону кармана → карман приоткрывается и подсвечивается,
элемент над ним уменьшается. `release` в зоне → элемент с анимацией улетает внутрь и исчезает с доски.

**Открыть.** Пустая рука над карманом 400 мс → содержимое раскрывается веером.
Прицел над элементом веера подсвечивает его.

**Достать.** `grab` над элементом веера → элемент уже в руке, тянется на доску, дальше обычное
поведение доски из S2.

**Два типа содержимого.**
- Заготовка, значок замка. Достаётся копия, заготовка остаётся.
- Убранное с доски. Достаётся сам элемент, из кармана он уходит.

**Листание.** Видно 6–8 элементов. Горизонтальное движение раскрытой рукой над веером листает.

## Режим подготовки

Переключатель в углу экрана «Подготовка». В нём карман управляется мышью:
- Ctrl+V вставляет картинку или текст из буфера как заготовку;
- перетаскивание файла картинки в карман создаёт заготовку;
- кнопка «Новый стикер» с полем ввода;
- удаление заготовок крестиком.

Хранение в IndexedDB. При первом запуске карман заполнен набором заготовок по умолчанию:
4 стикера с идеями, 2 фигуры, 1 картинка из `public/presets/`. Жюри проходит сценарий без мыши.

## Голос

Point на стикере → на стикере индикатор записи → Web Speech API `ru-RU`, промежуточный текст виден сразу,
финальный записывается в стикер через API доски. Окончание: пауза 1,5 секунды или повторный point.
Если API нет, подсказка «Голосовой ввод работает в Chrome, текст можно положить в карман заранее».

## Контекстные подсказки

Через `board.emitHint`:
- элемент удерживается у края кармана, но не в зоне → «Поднеси элемент ниже, к карману»;
- рука над карманом меньше 400 мс и уходит → «Задержи руку над карманом, чтобы он открылся»;
- в зоне кармана closure застрял 0.45–0.75 → «Разожми пальцы над карманом, чтобы положить элемент».
