# S4. Интеграция и сценарий

**Зона:** `src/app/**`, `index.html`, `public/sounds/**`.
**Зависит от:** S1, S2, S3.
**Результат:** законченный путь: открыл ссылку → калибровка → обучение → челлендж → финал.

## Экраны

1. **Старт.** Название, одна фраза о продукте, кнопка «Начать» с крупной зоной, которую можно
   активировать и мышью, и удержанием открытой ладони 1 секунду. Переключатель «Камера / Мышь» для отладки.
2. **Камера.** Запрос доступа. При отказе понятный текст и кнопка «Попробовать с мышью».
   Индикатор «Вижу руку» и подсказки S1 `TOO_FAR`, `TOO_CLOSE`, `POOR_TRACKING`.
3. **Калибровка.** Два шага из S1 с анимированной иллюстрацией руки.
4. **Обучение.** Четыре шага, каждый ждёт правильного действия и показывает подсказки при ошибке:
   взять и перенести стикер в рамку, бросить стикер в сторону, достать заготовку из кармана,
   положить элемент обратно в карман. Шаг можно пропустить удержанием ладони.
5. **Челлендж «Разбери брейншторм».** На доске 12 стикеров-идей, три подписанные зоны-кластера
   и корзина-бросок. Задача: разложить идеи по смыслу, 3 лишние выбросить, одну добавить из кармана
   или голосом. Таймер сверху. Раскладка проверяется по заранее заданной разметке.
6. **Финал.** Итоговая доска, время, точность раскладки в процентах, количество подсказок,
   самая частая ошибка и совет к ней. Экспорт PNG. Таблица рекордов из localStorage, ввод имени
   голосом или выбор из трёх вариантов прозвищ жестом. Кнопки «Ещё раз» и «Свободная доска».
7. **Свободная доска.** Без таймера, весь функционал.

## Подсказки

Единый слой для `hint` от камеры, доски и кармана. Тост рядом с прицелом, иконка нужного жеста,
не больше одной подсказки одновременно, приоритет warn над info, исчезает через 2,5 секунды или
после правильного действия. Для финала считать статистику подсказок по кодам.

## Звук

Короткие синтезированные через WebAudio звуки: захват, падение, бросок, карман, успех шага, финал.
Кнопка выключения звука. Никаких внешних аудиофайлов с неясной лицензией.

## Модули

| Файл | Ответственность | Чистый |
|---|---|---|
| `flow.ts` | машина экранов | да |
| `tutorial.ts` | шаги и условия прохождения | да |
| `challenge.ts` | данные челленджа, проверка раскладки, очки | да |
| `records.ts` | таблица рекордов | да, хранилище внедряется |
| `hint-layer.ts` | очередь и показ подсказок | логика да |
| `sound.ts` | WebAudio | нет |
| `export.ts` | PNG доски | нет |
| `screens/*.ts` | DOM экранов | нет |
