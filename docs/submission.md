# Описание для формы

Motion Board — доска для брейншторма, которой управляют руками через веб-камеру.
Открывается по ссылке: без установки, ключей и сервера. Распознавание идёт
в браузере, кадры никуда не уходят.

Зачем: есть экраны, до которых нельзя дотронуться — стерильная зона, руки
в перчатках, панель перед группой, общий экран в классе. Мыши там нет, а камера
есть в любом ноутбуке.

Направление: компьютерное зрение, распознавание жестов на устройстве.

Движения: кулак — взять элемент, раскрытая ладонь — отпустить, резкий бросок —
удалить, указательный палец с задержкой — кнопки, две руки в кулаке — зум, ладонь
над карманом — открыть карман, голос — текст стикера. Отдельный обученный класс
«рука в покое»: опущенную руку система не принимает за команду, можно отдохнуть.

Как устроено: MediaPipe HandLandmarker даёт 21 точку кисти, признаки считаются
в системе координат ладони, сглаживание One Euro, классификатор kNN, голосование
4 кадра из 6, гистерезис в машине состояний. На отложенном круге записи точность
97.9 %, ложных действий на бездействии 0 % — ноль кадров из 615. Правила по углам
пальцев на тех же данных дают 46.8 % ложных действий.

Режим «ошибка»: 32 кода подсказок, каждая отвечает «что сделать», а не «что
не так»: «Подойди на шаг ближе к камере», «Сожми кулак полностью, чтобы взять».
Условие должно продержаться, один код повторяется не чаще раза в 3 секунды.
При низкой уверенности система не действует, а подсказывает.
