Команда IITU404.

Motion Board — пульт, до которого не нужно дотягиваться: экраном управляют руками
через веб-камеру. Открывается по ссылке: без установки, ключей и сервера.
Распознавание идёт в браузере, кадры никуда не уходят.

Зачем: есть экраны, до которых нельзя дотронуться — стерильная зона, руки
в перчатках, общий экран перед группой. Мыши там нет, а камера есть в любом
ноутбуке. Сценарий показа — смена у пульта: сообщения разводятся по системам,
помехи выбрасываются в шлюз.

Движения: щипок или кулак — взять, раскрытая ладонь — отпустить, резкий бросок —
удалить, указательный палец с задержкой — кнопки, две руки — зум, ладонь над
карманом — открыть карман, голос — текст. Отдельный обученный класс «рука
в покое»: опущенную руку система не принимает за команду.

Как устроено: MediaPipe HandLandmarker даёт 21 точку кисти, признаки считаются
в системе координат ладони, сглаживание One Euro, классификатор kNN, голосование
по окну кадров, гистерезис в машине состояний. На отложенном круге записи точность
94.9 %, ложных действий на бездействии 11.4 %. Правила по углам пальцев на тех же
данных — 43.2 % и 71.4 %.

Строгость зависит от движения: пока рука летит, планка уверенности ниже — смаз
на махе ожидаем. Это нашлось разбором записи живого движения, а не набора поз.

Режим «ошибка»: 32 кода подсказок, каждая отвечает «что сделать», а не «что
не так». Подсказки не перебивают друг друга, а при низкой уверенности система
молчит, а не угадывает.
